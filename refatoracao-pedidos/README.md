# Refatoracao Arquitetural - Pedidos

Este material atende ao item **"Refatorando um Codigo com Problemas Arquiteturais"** do teste tecnico.

Estrutura:

- `problema/`: codigo original com acoplamento e responsabilidades misturadas.
- `proposta/`: exemplo de refatoracao com separacao por camadas e caso de uso explicito.

Objetivo:

- mostrar diagnostico arquitetural
- propor estrutura evolutiva e testavel
- tratar side effects (notificacao) sem acoplamento direto no controller
